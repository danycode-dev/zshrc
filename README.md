# Mi configuración de Zsh

Configuración personalizada de **Zsh** que uso en **Ubuntu y Arch**, incluyendo:

* Zsh
* Oh My Zsh
* Oh My Posh
* Plugins de Zsh
* `fzf`
* `eza`
* Nerd Fonts

---

## 📦 Instalación

### 1. Ir a `~/.config`

```bash
cd ~/.config
```

Si el directorio no existe:

```bash
mkdir -p ~/.config
cd ~/.config
```

### 2. Clonar este repositorio

```bash
git clone <URL_DEL_REPOSITORIO>
```

Luego entrar al directorio:

```bash
cd ~/.config/zshrc
```

### 3. Leer el README de instalación

Seguir las instrucciones de instalación indicadas en este repositorio.

---

## 📝 Nota

Esta configuración la saqué originalmente de unos **dotfiles para Arch Linux** y la adapté para que funcionara de forma independiente tanto en **Ubuntu como en Arch Linux**.
